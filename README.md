# ULTIMATE DRAGON - Native Android Jetpack Compose Project

## Hướng dẫn cài đặt và Build APK

### Cách 1: Dùng Android Studio (Dễ nhất)
1. Tải file ZIP này về và giải nén.
2. Mở Android Studio -> Chọn Open -> Chọn thư mục vừa giải nén.
3. Chờ Gradle tải thư viện và đồng bộ (sync).
4. Cắm điện thoại Android bật chế độ USB Debugging (Gỡ lỗi USB) hoặc mở máy ảo AVD.
5. Nhấn nút Run (Play màu xanh) hoặc vào menu:
   Build -> Build Bundle(s) / APK(s) -> Build APK(s)
6. File APK sẽ xuất hiện tại:
   app/build/outputs/apk/debug/app-debug.apk

### Cách 2: Chạy lệnh dòng lệnh (Terminal)
```bash
cd android
./gradlew assembleDebug
```
